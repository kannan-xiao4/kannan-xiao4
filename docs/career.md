# 経歴・技術実績

[プロフィールに戻る](../README.md)

Unity・C++・WebRTCを軸に、ゲーム、メタバース、ライブ配信領域で、機能開発、開発基盤整備、プロジェクト推進、チームマネジメントを経験してきました。

Unity向けのリアルタイム通信・映像配信基盤の開発、メタバースサービスのクライアントからクラウドまでを横断する開発リードを経て、現在はIRIAMで開発とチーム運営に取り組んでいます。技術的な制約とチームの状況を踏まえて課題を整理し、実装と仕組みづくりの両面から開発を進めることを強みとしています。

## IRIAM｜2025年9月〜現在

### 役割

2025年9月にクライアントエンジニアとして入社。同年11月から機能開発のリード・プロジェクトマネジメント（PjM）、2026年1月からグループリーダーとしてチーム運営を担っています。

### クライアント開発・プロジェクト推進

- アプリ内ホーム画面など、配信外領域のUI・機能開発。
- 機能開発からリリースまでのプロジェクト推進と、開発・リリースの調整。
- 複数の開発ラインを運営するためのチーム設計と、役割・期待値の整理。

### チームマネジメント・育成

- 主管チーム全体のピープルマネジメント。
- 直接評価者としてのメンバー評価、評価会での説明、本人へのフィードバック。
- 目標・役割設計、1on1、新卒・若手のメンタリング、課題解決の相談対応。
- 後任リーダーへの期待設定と、段階的な引継ぎ・権限移譲。
- プロジェクト管理の委任と、中長期の課題を見据えたチーム体制の検討。

自身が開発を進めることに加え、メンバーが判断・実行できる状態をつくることに取り組んでいます。個々のメンバーへの支援と、チーム全体の役割・責任・期待値をそろえることの両方を担っています。

## ソフトギア｜2023年9月〜2025年8月

### 役割

リードソフトウェアエンジニアとして、メタバースサービス「neem」の開発を担当しました。2024年8月から製品開発部長、2025年2月から開発本部副本部長を務めました。

### プロダクト開発

- Unityクライアント、Unity向けWebRTCライブラリ、APIサーバー、Webフロントエンド、GCP基盤の設計・実装。
- リアルタイムのテキスト・音声・映像通信、VRM、モバイル対応、ストリーミング機能の開発。
- ソフトウェア・ハードウェアデコードへの対応や、映像処理のマルチスレッド化。
- パフォーマンス改善とテストツールの整備。

### 開発体制・運用基盤の整備

- 外部委託領域の検収・内製化と、自社で開発・運用する体制の整備。
- 開発計画、チケット管理、リリース管理。
- 経営層、営業、法務などとの要件調整、工数・インフラ費用の見積もり。
- JenkinsやHelmfileを使ったCI/CD、負荷試験環境、運用手順、ドキュメントの整備。

### 主な実績

- サービス構成を踏まえて必要な開発範囲を整理し、着手から約半年でスマートフォン版をリリース。
- 外部委託していた開発・インフラ領域の内製化を推進。
- VRMの置き換えや、ストリーミングの複数受信に対応する機能を実装。

クライアントからインフラまでを一つのプロダクトの構成要素として捉え、領域をまたいで課題を調査し、実装と開発・運用体制の整備を進めました。

**主な技術**：Unity、C#、C++、WebRTC、Kotlin / Spring Boot / R2DBC、TypeScript / SvelteKit、PostgreSQL、GCP / GKE、Terraform、Jenkins。

## Unity Technologies Japan｜2020年2月〜2023年8月

### 役割・担当プロダクト

ソフトウェアエンジニアとして、Unity向けのリアルタイム通信・映像配信基盤の開発に携わりました。

- [Unity WebRTC](https://github.com/Unity-Technologies/com.unity.webrtc)
- [Unity Render Streaming](https://github.com/Unity-Technologies/UnityRenderStreaming)

### 通信・映像処理

- libwebrtcの更新と、Unity向けプラグインへの組み込み。
- 受信映像をUnityで扱うためのソフトウェア・ハードウェア映像デコーダーの実装。
- NvCodecを用いた映像受信機能の開発。
- エンコード・デコード処理のマルチスレッド化。

### 計測・接続・導入支援

- Unity Profilerとの統合によるパフォーマンス計測への対応。
- 通信状態を確認するための表示機能の整備。
- WebSocketシグナリング、Perfect Negotiation、Webクライアントとテストの整備。
- サンプル、セットアップウィザード、ドキュメントの整備。

通信ライブラリとUnityの描画・実行環境をつなぐ実装に取り組みました。機能の実装に加え、利用者が導入・検証でき、問題発生時に状態を調べられる環境も整えました。

**主な技術**：C++、C#、TypeScript、Unity、WebRTC / libwebrtc、NvCodec、Jest。

**主な技術**：Unity、C#、Jenkins。

## テクロス｜2017年3月〜2019年1月

ソフトウェアエンジニアとして新規ソーシャルゲーム開発に携わり、開発後半はサブリーダーを務めました。

- UnityによるUI・機能開発。
- CPU負荷・メモリ使用量などの最適化とリリース対応。
- JenkinsによるiOS・Android・WebGLおよびAssetBundleのビルド・デプロイ環境整備。
- Dockerによる開発環境の統一。
- 企画とのタスク調整と、運用・リリースサイクルの整備。

**主な技術**：Unity、C#、PHP / Laravel、Jenkins、Docker。
