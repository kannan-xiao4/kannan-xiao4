# 読書記録

読んだ本と、読んでいる本の記録です。技術や組織・マネジメントの本から、SFや漫画まで。
長い感想を書けないときも、読んだことを残していきます。

感想は読んだ当時のメモを短く整理しています。年は読書記録上の時期で、読了日を示すものではありません。「既読」は一部を読んだ記録を含みます。「読書中」は記録時点の状態です。
